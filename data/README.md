# Data

`events.csv.gz` — a part of the `events.csv` file of the *Retailrocket recommender system
dataset*: what a web shop's visitors did between 3 May and 18 September 2015, one row per
event. The published file has 2,756,101 events from 1,407,580 visitors. This file has
915,592 events from 469,405 visitors, one visitor in three, over the same period. No value
is altered. How the cut was made is not recorded.

Source: Retailrocket, on Kaggle,
